Why Sisonke

You found the perfect designer online, half a world away. You’ve never met. So who pays first?

With Sisonke, nobody has to guess. The money waits in a Stellar smart contract where you can both see it, and it only ever moves toward the other person.

The one rule

Money only moves toward the other person.

The payer can release it but can’t pull it back early. The recipient can refund it but can’t pay themselves. The contract checks every signature, so the rule holds even if someone skips this website.

How it works

Three steps from handshake to payout.

  1. 01
    CreateWho gets paid, how much, and a deadline. One signature saves it on-chain.
  2. 02
    DepositThe USDC moves into the contract. The other side can see it’s really there.
  3. 03
    Release or refundThe payer releases when the work is in. The recipient refunds if it falls apart. It’s final either way.
